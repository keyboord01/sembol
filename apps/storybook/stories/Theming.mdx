# Theming

Every visual decision in the default stylesheet is a **CSS custom property** - restyle
without forking. Use the **Theme toolbar button** (🖌 top bar) to preview any story in
light/dark.

## Setup

```ts
import "@sembol/passkey-react/styles.css"; // once, app-wide
```

## Zero-CSS theming: the `theme` prop

Pass a typed `SembolTheme` to the provider and skip CSS entirely. One `accent`
retints the whole kit - hover, active, muted, and the focus ring derive from it
per color scheme:

```tsx
<PasskeyWalletProvider
  config={config}
  theme={{ accent: "#e11d48", radius: "lg", colorScheme: "auto" }}
>
```

- `colors` / `darkColors` override any of the 19 tokens per scheme
- `radius`: `"none" | "sm" | "md" | "lg" | "full"` or a number in px
- `fonts.body` / `fonts.mono`, `shadows: false` for flat UIs
- `colorScheme`: `"light" | "dark" | "auto"` (the provider manages `data-sembol-theme`)
- Presets: `theme={sembolThemes.seal}` (or `ocean`, `forest`, `mono`) - spread and override
- Advanced: `sembolThemeToCss(theme, ".checkout")` scopes a theme to one subtree

Try it live in **Theming → Playground**, which generates the exact `theme` prop
to copy. Everything below still works on top: the prop compiles to the same
CSS custom properties.

Prefer fully custom markup? Pass `unstyled` to any component to drop all `sembol-*`
classes, or skip the stylesheet entirely and build on the headless hooks.

## Design tokens

Override in your own CSS after the import:

```css
:root {
  --sembol-color-accent: #e11d48;        /* brand color */
  --sembol-color-accent-hover: #be123c;
  --sembol-radius: 6px;
  --sembol-font: "Inter", sans-serif;
}
```

| Variable | Purpose |
| --- | --- |
| `--sembol-color-accent` / `-hover` / `-active` / `-muted` / `--sembol-color-on-accent` | Primary buttons, links, badges |
| `--sembol-color-bg` / `--sembol-color-surface` / `--sembol-color-surface-hover` | Backgrounds: page, cards, hover states |
| `--sembol-color-fg` / `--sembol-color-fg-muted` | Text |
| `--sembol-color-border` / `--sembol-color-border-strong` | Borders, dividers, hover borders |
| `--sembol-color-success` / `-strong` / `-muted`, `--sembol-color-danger` / `-strong` / `-muted` | Status text + tinted status panels |
| `--sembol-color-overlay` | Modal backdrop |
| `--sembol-radius-sm` / `--sembol-radius` / `--sembol-radius-lg` / `--sembol-radius-full` | Corner radii |
| `--sembol-font` / `--sembol-font-mono` | Type stacks |
| `--sembol-shadow-sm` / `--sembol-shadow` / `--sembol-shadow-lg` / `--sembol-shadow-xl` | Elevation scale |
| `--sembol-focus-ring` | Focus outline |
| `--sembol-ease` / `--sembol-duration` | Motion (respects `prefers-reduced-motion`) |

## Button variants & sizes

The built-in buttons take `variant` and `size` props:

```tsx
<CreateWalletButton variant="primary" size="lg" />
<ConnectWalletButton variant="outline" size="sm" />
```

Variants: `primary` · `secondary` · `outline` · `ghost` · `destructive` - see the
*Variants* and *Sizes* stories under each button component.

## Dark mode

Automatic via `prefers-color-scheme` by default. To control it explicitly, set
`data-sembol-theme` on `<html>` (or any ancestor):

```html
<html data-sembol-theme="dark">  <!-- or "light" -->
```

## Tailwind CSS v4

The tokens are plain CSS variables, so they compose naturally with Tailwind v4's
CSS-first theming - map them into your `@theme` to reuse Sembol's palette in utilities,
or drive Sembol from your design system:

```css
@import "tailwindcss";
@import "@sembol/passkey-react/styles.css";

/* Drive Sembol from your Tailwind tokens */
@theme {
  --color-brand-600: oklch(0.55 0.2 275);
}
:root {
  --sembol-color-accent: var(--color-brand-600);
}
```

Components also accept `className`, so Tailwind utilities can be layered directly:

```tsx
<CreateWalletButton className="w-full shadow-lg" />
```
